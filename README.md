# Student-Record-Academic-Management-System
Python-based Student Record and Academic Management System using lists, tuples, sets, dictionaries, and strings. -
STUDENT RECORD AND ACADEMIC MANAGEMENT SYSTEM
Data Organization using Python

Student: BANDARU CHANDU
Program: B.Tech AIML
Year / Division: FY AIML - A | Division A
University: Sanjivani University

FEATURES
- Add, search, update and delete student records
- Display student records
- Calculate average marks
- Generate an academic report and find the highest scorer
- List students by department and count records
- Demonstrates strings, lists, tuples, sets and dictionaries

REQUIREMENTS
Python 3; no third-party packages required.

HOW TO RUN
1. Download the Python source file.
2. Open a terminal in the folder containing the file.
3. Run:
   python BANDARU_CHANDU_Student_Record_Academic_Management_System_FINAL.py

DATA NOTE
The program starts with fictional demonstration records. Changes are kept in memory only
and are not saved after the program exits.
